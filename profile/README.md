## 🌊 Tentang MuaraAI

MuaraAI adalah wadah independen mahasiswa Indonesia untuk belajar, berkolaborasi, dan membangun portofolio berbasis **Proof of Work**. Kami percaya bahwa karya berstandar global dapat lahir dari kampus mana pun di nusantara.

- **Founding Hub:** Pontianak, Kalimantan Barat (UBSI Pontianak).
- **Cakupan:** Terbuka untuk seluruh mahasiswa kampus di Indonesia (angkatan 2026+).
- **Prinsip Utama:** Open-source first, no filler, bukti karya nyata (Proof of Work), dan riset yang dapat direproduksi.

## 🚀 Proyek Unggulan

### 1. [Muara Arus 1](https://github.com/MuaraAI/muara-arus-1)
Small Language Model (SLM 1.5B parameter) yang dirancang khusus untuk berjalan **100% offline di perangkat lokal**. Dilatih untuk memahami kurikulum akademik teknologi informasi Indonesia, arsitektur software, dan penulisan kode.
- **Tersedia di:** [Web Playground](https://ai.muaraai.com) · [Hugging Face](https://huggingface.co/MuaraAI/muara-arus-1) · [Ollama](https://ollama.com/MuaraAI/muara-arus-1)

### 2. [UBSI API](https://github.com/MuaraAI/UBSI-API)
REST API Aggregator independen berkinerja tinggi yang mengonsolidasikan 6 layanan digital kampus UBSI (SIAKAD/StudentV2, MyBest Elearning, E-Library, E-Journal, Repository, dan News Portal) menjadi antarmuka JSON modern berbasis FastAPI dan Redis.
- **Tersedia di:** [ubsi-api.muaraai.com](https://ubsi-api.muaraai.com)

### 3. [MuaraAI Portal](https://github.com/MuaraAI/MuaraAI)
Website resmi dan sistem portal komunitas di [muaraai.com](https://muaraai.com). Dilengkapi peta jaringan universitas se-Indonesia, alur pendaftaran Proof of Work terverifikasi, direktori anggota publik, dan dashboard pembelajaran interaktif.

### 4. [Laku](https://github.com/MuaraAI/laku)
Engine prediksi restock dan inventaris berbasis data multi-marketplace (Shopee, TikTok Shop, Tokopedia) untuk UMKM Indonesia — Proyek Hackathon SIFEST 2026.

### 5. [Harness DC](https://github.com/MuaraAI/harness-dc)
Daemon Discord Rich Presence ringan untuk autonomous AI coding agents (Hermes Agent & Antigravity) dengan integrasi multi-agent workspace zero-config.

## 🤝 Bergabung dengan Komunitas

Pendaftaran anggota MuaraAI berbasis **Proof of Work (PoW)** untuk menjaga kualitas kolaborasi:

1. Kunjungi portal resmi di **[muaraai.com/onboarding](https://muaraai.com/onboarding)**.
2. Lengkapi data identitas kampus dan tautan portofolio/karya yang pernah Anda buat.
3. Setujui ketentuan etika dan kode etik komunitas.
4. Hubungkan akun GitHub Anda untuk verifikasi dan review oleh tim maintainer.
