MuaraAI adalah komunitas mahasiswa lintas kampus di Indonesia yang membangun software,
sistem AI lokal, dan riset terbuka. Komunitas ini berawal dari mahasiswa UBSI Pontianak,
Kalimantan Barat, dan terbuka untuk mahasiswa kampus mana pun mulai angkatan 2026.
Setiap anggota bergabung dengan menunjukkan karya yang pernah dibuat (Proof of Work), dan
proyeknya mengutamakan open source serta riset yang bisa diulang orang lain.

[muaraai.com](https://muaraai.com) · [AI Playground](https://ai.muaraai.com) · [UBSI API](https://ubsi-api.muaraai.com) · [Hugging Face](https://huggingface.co/MuaraAI) · [Ollama](https://ollama.com/MuaraAI/muara-arus-1)

## Proyek

### [Muara Arus 1](https://github.com/MuaraAI/muara-arus-1)

Model bahasa kecil (1,5 miliar parameter) yang berjalan offline di perangkat sendiri.
Dilatih untuk materi kuliah teknologi informasi, arsitektur software, dan menulis kode.
Coba di [Web Playground](https://ai.muaraai.com), [Hugging Face](https://huggingface.co/MuaraAI/muara-arus-1), atau [Ollama](https://ollama.com/MuaraAI/muara-arus-1).

### [FluxCode](https://github.com/MuaraAI/FluxCode)

Editor kode native untuk Windows dan Linux, ditulis dengan Rust: panel agent AI dengan
tiga level akses, terminal yang ramah Python, Source Control bawaan, dan tanpa telemetri.
Dibuat oleh mahasiswa semester 1 dan masih dalam pengembangan.
[Download build terbaru](https://github.com/MuaraAI/FluxCode/releases/latest).

### [UBSI API](https://github.com/MuaraAI/UBSI-API)

REST API independen yang menyatukan enam layanan digital kampus UBSI (SIAKAD/StudentV2,
MyBest Elearning, E-Library, E-Journal, Repository, dan News Portal) dalam format JSON.
Dibangun dengan FastAPI dan Redis. Bisa dipakai di [ubsi-api.muaraai.com](https://ubsi-api.muaraai.com).

### [MuaraAI Portal](https://github.com/MuaraAI/MuaraAI)

Website komunitas di [muaraai.com](https://muaraai.com): peta kampus anggota di seluruh
Indonesia, pendaftaran lewat karya yang terverifikasi, direktori anggota, dan dashboard
belajar.

### [Laku](https://github.com/MuaraAI/laku)

Prediksi restock dan stok untuk UMKM dari data Shopee, TikTok Shop, dan Tokopedia.
Proyek Hackathon SIFEST 2026.

### [Harness DC](https://github.com/MuaraAI/harness-dc)

Daemon Discord Rich Presence yang ringan untuk agent coding AI (Hermes Agent dan
Antigravity), bisa langsung dipakai tanpa konfigurasi.
